达尔文（Darwin, NT）移动端/软件开发求职报告¶ ↑

对象：33 岁；约 10 年 Android 开发经验；约 4 年 Flutter 开发经验。
目标：计划于明年 6 月前往澳大利亚北领地 Darwin 求职。
本报告口径：当前日期按 2026-09-13 记录，因此“明年 6 月”按 2027 年 6 月理解；如果你的实际计划是 2026 年 6 月，请将时间表整体前移。
调研快照：2026-09-13；职位会快速变化，以下结果用于判断市场结构和岗位匹配，不代表 2027 年 6 月仍然开放。

1. 结论先行¶ ↑

最重要的判断¶ ↑

  1. Darwin 本地纯 Android/Flutter 岗位非常少。 本次可访问的 Jora 快照中，关键词结果大致为：Android Developer 3 个、Flutter Developer 2 个、Mobile Developer 9 个；但这些结果存在聚合站重复匹配，实际独立岗位明显少于数字。

  2. 你的最佳策略不是只搜索 Android Developer，而是把自己包装成 Senior Software Engineer / Application Developer / Integration Developer（移动端和 API 背景），并同时寻找 Darwin 本地、澳洲远程、允许在 NT 工作的岗位。

  3. 你与 Darwin 市场最接近的方向按优先级为：

  4. A 档：Senior Software Engineer / Application Developer：保留移动端优势，同时补齐 Web/API/云端能力。

  5. A- 档：Integration Developer / API Developer：Android 对 REST、鉴权、JSON、异步、可靠性和端到端排障的经验可迁移；但通常要补 .NET/C#、数据库和企业集成平台。

  6. B 档：Cross-platform / Mobile Application Developer：最贴近个人经历，但岗位数量和本地雇主基数有限。

  7. B 档：Technical Lead / Application Support Engineer / Systems Analyst：适合有架构、交付、客户沟通和故障处理经历的候选人；不应把自己降级成初级 IT Support。

  8. 选择性投递：政府/国防相关 Senior Application Developer、Salesforce/Vlocity、Azure Application Architect：薪酬和稳定性可能较好，但往往有澳洲公民身份、Baseline clearance 或具体平台要求。

  9. 签证/工作权是第一道筛选，不是到达后再考虑的问题。 没有澳洲工作权或明确的雇主担保路径，即使技术匹配，也可能在简历筛选阶段被淘汰。

  10. 如果 Darwin 是不可妥协的地点，应从现在开始准备“本地岗位 + 澳洲远程岗位 + 北领地政府/大学/医疗/国防承包商”三条管线；如果地点可以调整，建议把 Perth、Brisbane、Adelaide、Melbourne、Sydney 的远程/混合岗位纳入，否则纯 Darwin 移动开发市场风险很高。

岗位 1：Software Engineer — Skills and Hands NT Pty Ltd（Jora）¶ ↑

  • 地点：Darwin NT；全职。

  • 公开摘要薪酬：A$79,500–100,000/年。

  • 主要职责：设计、开发和维护可扩展 Web 应用；对接第三方平台和医疗系统；使用 API；关注安全、隐私、可靠性和性能。

  • 与你的匹配点：Android 端对 API、网络错误、认证、性能、隐私、线上问题定位的经验可直接迁移；10 年经验足以覆盖成熟度要求。

  • 建议岗位标题：Senior Software Engineer、Application Developer、Mobile/Backend Engineer。

岗位 2：Integration Developer — Charles Darwin University（Jora）¶ ↑

  • 地点：Darwin NT；全职。

  • 公开摘要薪酬：A$96,559–105,992/年。

  • 主要职责：为大学开发可扩展系统集成；与业务利益相关者、供应商和主题专家合作；要求集成平台和 API 管理经验。

  • 与你的匹配点：移动端通常需要对接多个 REST API、处理认证、缓存、重试、版本兼容和数据映射；这可以作为集成开发的基础故事。

  • 主要缺口：企业集成平台、API gateway、消息队列、ETL/数据映射、SQL、供应商和业务沟通经验。

  • 判断：这是比“纯 Android”更值得长期准备的 Darwin 方向。应在 2027 年前做一个可展示的 API integration 项目，并补 C#/.NET 或 Java/Spring 之一。

岗位 3：Integration .NET Developer — Centorrino Technologies（Adzuna）¶ ↑

  • 地点：Darwin NT；12 个月 fixed-term contract。

  • 主要职责：用 C#/.NET 开发和支持系统间集成；双向数据交换；REST API；JSON/XML；集成模式；.NET Framework 与 .NET 6+；单元测试；Git、CI/CD；技术设计、数据库模型、排障和集成测试。

  • 硬性要求：约 5 年 C#/.NET 和约 5 年系统集成经验。

  • 与你的匹配点：你有长期商业软件交付、API、测试、版本控制和线上问题处理能力，这些软硬能力可迁移。

  • 主要缺口：C#/.NET 不是短期“看过教程”即可替代；还需 SQL、依赖注入、WPF/XAML 或 Web 应用、CI/CD 和企业架构。

  • 投递建议：如果你的经历中有 Java/Kotlin 服务端、微服务、数据库或后端项目，可作为过渡投递；否则将其作为技能转型目标而不是当前最高成功率岗位。

岗位 4：EL1 Senior Vlocity Software Developers — Softtest pays（Adzuna）¶ ↑

  • 地点：Darwin；全职/永久性质展示。

  • 硬性要求：澳洲公民并能够获得 Baseline clearance；Salesforce Vlocity、Apex、LWC、OmniScripts、FlexCards、Integration Procedures、DataRaptors；相关 Salesforce 认证；GitLab、Agile、REST/API、DevOps、可访问性。

  • 与你的匹配度：通用 OOP、REST、Git、敏捷、集成和可访问性思维可迁移，但 Salesforce/Vlocity 平台要求构成决定性门槛。

  • 建议：除非你愿意转向 Salesforce，并且满足公民/clearance 条件，否则不应作为主投方向；可把类似 JD 当作观察 Darwin 政府/国防数字项目技术生态的样本。

岗位 5：GIS Developer / Technical Analyst / Test Analyst¶ ↑

  • GIS Developer 摘要涉及 Geocortex、VertiGIS Studio、ArcGIS Enterprise、.NET、JavaScript、PostgreSQL。

  • Technical Analyst 摘要涉及 Jira、Confluence、IT 基础设施、安全、网络、数据库、Docker 以及 Atlassian Server 到 Cloud 迁移。

  • Test Analyst 摘要涉及端到端测试、测试用例、数字化转型项目，部分岗位要求 ISTQB。

  • 结论：这些是“相邻 ICT 岗位”，不是你的首选。若你有自动化测试、发布管理、Docker、故障排查、业务分析或平台维护经历，可以作为备选；不要仅凭 Android 年限声称完全匹配 GIS、网络或测试专业岗位。

7. 签证、年龄与资格风险¶ ↑

  • 33 岁不是技术求职障碍，反而意味着你应以中高级职位和独立交付能力定位，而不是 graduate/junior。年龄更多影响某些技术移民计分和具体签证条件，须按申请时官方规则核验。

  • 澳大利亚内政部的 Skilled Occupation List 页面说明，相关签证使用职业代码、职业清单、caveat 和技能评估机构；同时存在不同 ANZSCO 版本，职业选择必须对应真实职责。

  • ACS 公开说明会评估学历 ICT 内容、相关工作经验和职业职责；其网站也提示完整评估通常需要数周，且材料要在提交时准备齐全。应尽早检查学历相关性和工作证明，而不是在拿到 offer 后才开始。

  • Darwin 位于北领地，属于区域市场；491/494 等区域或雇主相关路径是否适用，取决于当期州/领地配额、提名条件、职业清单、英语、年龄、工作经验和工作权。不要仅因为“Darwin 是 regional”就假定一定能移民。

  • 政府、国防和部分承包商职位常要求 Australian citizenship、Baseline/NV1 等 security clearance；如果你目前不是公民，需在投递前阅读 eligibility，避免把时间花在明显不符合的岗位上。

  • 本报告不替代注册移民代理或律师意见；签证条件以 Department of Home Affairs 和 Northern Territory Government 在申请时发布的官方页面为准。
